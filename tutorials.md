GameLoop setup process
1. Install GameLoop from official website ( 32bit / 64bit / Chinese doesn't matter )
2. Install X ( twitter ) from appmarket . 
3. After it opens , close GameLoop and click launch in Fusion. (Don't worry about BGMI being not installed ) 
4. After launching from fusion GameLoop, install BGMI from installer . Extract the installer first then run install.bat file
5. After install click launch from fusion and u are done..

Keymapping SetUP : https://t.me/snailytchat/874245
For Keymapping in GameLoop
1. Open Tools in Fusion , go to Gameloop section and download snailyt.exe 
2. open that and set keymap according to resolution. 
3. Do this only after Gameloop is installed.
